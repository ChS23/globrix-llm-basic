# 🏡 **globrix-llm-basic**  
**Мультиагентная система для риэлторов: интеллектуальный сбор и презентация данных по недвижимости в регионе**

# 🧩 Агент-оркестратор

**Назначение:** координация и маршрутизация запросов между тулзами и агентами (RAG, GenUI, поиск недвижимости).  
**Технологии:** LangGraph, FastAPI, MemorySaver.

---

## 🧠 Описание

Агент-оркестратор — это **центральный узел** мультиагентной системы `globrix-llm-basic`. Он:

- принимает запросы от пользователя (через FastAPI),
- анализирует их на предмет задачи (поиск недвижимости, генерация лэндинга, вопросы о районе),
- вызывает соответствующие **тулзы**,
- сохраняет состояние диалога (с помощью чекпоинтера),
- возвращает результат пользователю

---

## 🏗️ Архитектура

### Файлы:

| Файл | Назначение |
|------|------------|
| `agent.py` | Основной граф оркестратора, маршрутизация |
| `state.py` | Кастомное состояние диалога |
| `constants.py` | Константы узлов и статусов |
| `schemas/` | Pydantic-модели для типизации |
| `tools/` | Тулзы, вызываемые оркестратором |

---

## 🛠️ Используемые тулзы

| Тул | Назначение | Ответственный |
|-----|------------|---------------|
| `realty_search` | Поиск объектов недвижимости по фильтрам | Анна |
| `regional_rag_tool` | Ответы на вопросы о регионе | (обёртка) |
| `genui_tool` | Генерация лэндингов | (обёртка) |

---

## 🧪 Пример работы

1. Пользователь: *"Найди 2-комнатную квартиру в центре."*
2. Оркестратор:
   - распознаёт задачу → вызывает `realty_search`
   - получает результат → возвращает пользователю
3. Пользователь: *"Сделай лэндинг."*
4. Оркестратор:
   - вызывает `genui_tool`
   - получает HTML → возвращает пользователю

## 🚀 Запуск

Оркестратор запускается как часть основного приложения:

```bash
python -m uvicorn main:app --reload
```

Доступен через `/chat` (POST).
